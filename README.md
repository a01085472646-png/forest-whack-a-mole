# 🌿 숲속 두더지 잡기 (Forest Whack-A-Mole)

> 자연 속 숲속 정원을 테마로 한 아기자기하고 귀여운 5×5 캐주얼 두더지 잡기 웹 미니게임입니다. 🍃

---

## ✨ 게임 특징

- **🌱 싱그러운 숲속 정원 테마**: 동화 같은 자연 배경과 잔디밭, 입체 흙구멍 애니메이션.
- **🐹 귀여운 5종류의 두더지 캐릭터**:
  - 🌰 **일반 두더지 (+10점)**: 갈색 털과 분홍 코를 가진 기본 두더지
  - 🍞 **베이지 두더지 (+15점)**: 베이지 털과 분홍 볼터치를 한 방긋 웃는 두더지
  - 🍄 **버섯 두더지 (+20점)**: 빨간 버섯 갓 모자를 쓴 두더지
  - 🌸 **꽃 두더지 (+25점)**: 머리에 작은 꽃 장식을 단 초롱초롱한 두더지
  - ✨ **황금 두더지 (+50점 - 희귀)**: 화려한 금빛 오라와 왕관을 쓴 스페셜 두더지
- **🎮 5×5 총 25개의 게임판**: PC와 모바일 반응형 완벽 대응.
- **⏱️ 30초 스릴 넘치는 타이머**: 실시간 점수 판정 및 브라우저 `localStorage` 기반 최고 기록 저장.
- **🔊 Web Audio API 순수 효과음**: 외부 음원 없이 팝, 뿅, 맑은 벨, 팡파레 사운드 직접 합성 (음소거 토글 지원).
- **💥 풍성한 인터랙션**: 잡았을 때 부유하는 점수 텍스트와 별/꽃잎 파티클 폭죽.

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, Vanilla CSS, Modern JavaScript (ES6+)
- **Audio**: Web Audio API (Synthesizer)
- **Deployment**: Vercel

---

## 🚀 로컬 실행 방법

별도의 복잡한 설치 없이 브라우저에서 바로 열 수 있습니다:

```bash
# 또는 간단한 로컬 정적 서버로 실행
node server.js
```
브라우저에서 `http://localhost:3000` 접속
